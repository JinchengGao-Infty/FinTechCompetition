# MiniMax语音连接

在“我的 → 模型与连接 → 语音 MiniMax”由用户自行输入Key。对话模型与语音模型分开，语音连接不覆盖DeepSeek。Key仅存当前服务会话RAM，不回显、不写localStorage、日志、.env或导出。沿用既有会话过期规则；重启或过期需要用户重新输入。连接操作本身不验证上游、不调用收费接口。

连接说明明确授权仅待播报脱敏speak与音色参数发往MiniMax中国站。不上传录音、声纹、完整聊天或账本。真实姓名和金额即使不属于号码类也可能出现在speak，因此排练使用虚构数据；不是承诺供应商零留存。

点击“试听一句”只播放一条固定非敏感短句；可停止。不会后台循环测试、自动充值或购买订阅。当前固定speech-2.8-hd与官方系统音色Chinese (Mandarin)_Warm_Bestie，不自建或克隆音色。官方列表：https://platform.minimax.io/docs/faq/system-voice-id 。声音自然度必须由用户实际试听评价。

本地上限2000估算计费字符；按每个输入字符最多2个计费字符保守预留，失败或中断不退回估算，重连不清零。显示的是本地会话估算，不是供应商余额或最终账单。达到上限停止新请求。

独立适配器负责二次遮蔽、PCM音频流与播放队列。核心同源路由负责Origin、CSRF、会话、重复请求、限额和取消。断开使旧generation失效，迟到音频不继续发送；前端取消清播放队列并请求取消上游。失败保留文字并提示，不静默切回旧声音。原ASR、单麦克风与操作确认门控保留。
